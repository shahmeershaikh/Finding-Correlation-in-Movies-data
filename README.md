# Movie Correlation Analysis

## Project Overview
This project analyzes movie data to find correlations between various movie attributes. The analysis uses Python data science tools to explore relationships between movie features such as ratings, revenue, budget, and other key metrics.

## Data Cleaning Process
The data preparation phase included:
- **Removed Duplicates**: Eliminated duplicate entries to ensure data integrity
- **Removed .0 Decimals**: Cleaned unnecessary decimal values for cleaner data representation
- **Data Validation**: Ensured consistency across all movie records

## Dataset
The analysis is performed on a comprehensive movie dataset containing various attributes including:
- Movie ratings and scores
- Revenue and budget information
- Release dates and genres
- Cast and crew information
- Runtime and other metadata

## Key Findings
This project identifies and visualizes correlations between different movie attributes, helping to understand which factors are most strongly related to movie success and audience reception.

## Tools & Technologies
- **Python**: Core programming language
- **Pandas**: Data manipulation and cleaning
- **NumPy**: Numerical computations
- **Matplotlib/Seaborn**: Data visualization
- **Jupyter Notebook**: Interactive analysis environment
