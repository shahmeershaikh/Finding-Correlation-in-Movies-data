## Data Cleaning

Data cleaning is an essential step in preparing the dataset for analysis. In this project, the following data cleaning steps were performed:

1. **Removing Duplicates:** Any duplicate rows were identified and removed to ensure that each entry in the dataset is unique.
2. **Handling .0 Values:** Values that had a decimal point followed by a zero (e.g., `5.0`) were converted to integer format to maintain consistency in data types.
3. **Changing Data Types:** Various columns had their data types changed to more appropriate types to facilitate analysis and ensure accurate computations. This includes converting string representations of numbers to integers/floats where applicable.
